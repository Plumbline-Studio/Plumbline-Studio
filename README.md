# Plumbline Studio

**Build it true.**

A plumb line is a weight on a string. It shows you what is straight. It does not guess.

That is how I build. I make business tools with AI, and I also build the checks that test them. So when I say a tool works, you can see the proof.

Plumbline Studio LLC builds apps, portals and AI tools for partners and business owners. Founded by Kyle Knight in Roanoke, Virginia, in 2026.

I'm Kyle Knight. I build systems that help a business grow past what its owner can carry alone. Partners bring me the builds their clients need. I build them, test them and hand them back.

## Things you can look at

- **[Plumb-bob](https://github.com/Plumbline-Studio/Plumb-bob)**: checks every code change three ways before it goes in. Does it work? Does it match the plan? Should it be built this way? It can stop a bad change.
- **[plumb-bob-console](https://github.com/Plumbline-Studio/plumb-bob-console)**: a dashboard for Plumb-bob's reports.
- **[The Build Atlas](https://github.com/Plumbline-Studio/plumbline-build-atlas)**: helps you pick the tools for a new build. It scores each choice and shows you why.
- **[tool-maker-app](https://github.com/Plumbline-Studio/tool-maker-app)**: records talks with experts and turns them into build plans. [Live](https://app.toolwright.dev)
- **[OWT-community](https://github.com/Plumbline-Studio/OWT-community)**: an app for makers, built so it doesn't steal your attention. [Live](https://oldworldtrade.shop)
- **[Amoeba](https://github.com/Plumbline-Studio/Amoeba)**: a 3D particle world I built for fun. [Try it](https://plumbline-studio.github.io/Amoeba/)
- **[true-vertical](https://github.com/Plumbline-Studio/true-vertical)**: a way to turn a psych evaluation into a personal guide. Free to share.
